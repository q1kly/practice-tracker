Practice Tracker — мобильное приложение, разработанное в рамках учебной практики. Приложение реализует демонстрационную модель системы сопровождения прохождения практики на предприятии с разделением пользователей по ролям. Разработка выполнена в среде Android Studio с использованием языка программирования Java и XML-разметки интерфейса.
В приложении реализована упрощённая система входа. Пользователь вводит произвольные данные и выбирает одну из трёх ролей: стажёр, ментор или куратор. Проверка корректности логина и пароля в учебной версии не осуществляется. Выбранная роль сохраняется с использованием механизма SharedPreferences и определяет доступный функционал.
Для роли стажёра предусмотрен главный экран с отображением текущего статуса прохождения блока и информации о дедлайне. Стажёр может перейти к списку заданий, просмотреть описание конкретного задания и отправить ссылку на выполненную работу, например на репозиторий GitHub. При отправке реализована проверка заполнения поля ссылки и вывод информационного сообщения. Также стажёру доступен раздел документов, в котором отображается демонстрационный список документов, связанных с практикой.
Для роли ментора реализован экран очереди проверок, на котором отображаются работы стажёров, ожидающие проверки. При выборе работы открывается экран проверки, где ментор может ввести комментарий и принять решение о результате выполнения задания: принять работу или отправить её на доработку. Изменение статуса в учебной версии реализовано в виде демонстрационного уведомления.
Для роли куратора реализован экран контроля практики, содержащий сводную информацию о количестве стажёров, работ на проверке и просроченных заданиях. Куратор может просматривать проблемные категории и инициировать отправку напоминаний. Данные в данном разделе являются демонстрационными.
Приложение не использует базу данных и серверную часть. Все данные и статусы носят имитационный характер и предназначены для демонстрации структуры мобильной системы и распределения функционала между ролями.
В репозитории используются две основные ветки. Ветка project содержит исходный код Android-приложения и файл README.md с актуальной информацией о проекте. Ветка report содержит отчёт по практике в формате документа Word.
